# شحن — موقع واحد على Netlify

رابط واحد فقط. أول مرة تفتحه يسألك: موظف لو محاسب؟ ويتذكر اختيارك على الجهاز.
(زر «تغيير الدور» فوق إذا تريد تبدل.)

## النشر
1. ارفع هذا المجلد (بعد فك الـ zip) إلى مستودع GitHub.
2. Netlify ← Import from Git ← اختر المستودع. الإعدادات تنقرأ من netlify.toml تلقائياً.
3. اضغط Deploy. ماكو متغيرات لازم تضبطها.

## كلمة المرور (اختيارية)
بدون ضبط شي، الموقع مفتوح لأي شخص عنده الرابط. إذا تريد تقفله لاحقاً:
Site configuration ← Environment variables ← أضف OFFICE_PASSWORD (16 حرف أو أكثر) ← Deploy جديد.

## فحص سريع
افتح `رابطك/api/orders`. إذا طلع `[]` أو `{"error":"سجّل الدخول"}` فالخادم شغال.
إذا طلع صفحة الموقع أو 404 فـ Functions ما انرفعت (غالباً لأنك رفعت ملفات بدون بناء).
